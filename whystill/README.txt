WHY STILL — PREMIUM WEBSITE

This package contains a complete responsive static website:
- index.html — premium one-page corporate website
- grilens.html — dedicated GRI-Lens case-study page
- styles.css — responsive brand system
- script.js — reveal animations, mobile navigation, contact-form behavior
- site-config.js — one place to enter business email / Instagram / WhatsApp
- assets/ — logo, mascot, portfolio visuals, Instagram visuals, company profile PDF

PREVIEW
Open index.html directly, or run:
python -m http.server 8000
Then open http://localhost:8000

BEFORE GOING LIVE
1. Edit site-config.js and add your real email + Instagram URL.
2. If you already own a domain, update the SEO canonical/OpenGraph metadata.
3. Replace the mailto-based inquiry form with Formspree, Netlify Forms, a custom backend, or your CRM.
4. Add privacy policy / terms if you collect data.
5. Optimize images to WebP/AVIF for production speed.
6. Deploy to Cloudflare Pages, Netlify, Vercel, GitHub Pages, or your own hosting.
